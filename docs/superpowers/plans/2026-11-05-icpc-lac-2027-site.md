# ICPC LAC 2027 Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page "postcard journey" website for the 2027 ICPC Latin America Championship in Monterrey, using the user's vector postcards, a cream "paper" look and bold ICPC colors with contest balloons.

**Architecture:** Vite + React 19 + TypeScript + MUI 7 single-page app with no router. Reusable presentational components live in `src/components/` and receive everything via props; all copy and event facts live in typed `src/content/*.ts` files; `src/sections/*` and `App.tsx` are the only places content meets components. Postcard SVGs are exported to responsive WebP by a `sharp` script.

**Tech Stack:** Vite 6, React 19, TypeScript 5.8, MUI 7 + Emotion, react-intersection-observer 9, vite-plugin-svgr 4, ESLint 9 + typescript-eslint, Vitest 3 + Testing Library + jsdom, sharp (dev only).

**Spec:** `docs/superpowers/specs/2026-11-05-icpc-lac-2027-site-design.md`

## Review Focus

1. **Countdown target written without a timezone offset** (e.g. `2027-11-12T09:00:00`) would be read in each visitor's local time; the target must carry `Z` or `±HH:MM` → pinned by the content test in Task 5.
2. **Site deployed under a sub-path** (e.g. `example.edu/icpc2027/`) must still load postcard images → pinned by `withBase` tests in Task 2 and the `srcSet` test in Task 7.
3. **Page left open across the start time** must switch to "The championship has started" without negative numbers or a stalled timer → pinned by the crossing test in Task 3.
4. **Keyboard-only visitor** must be able to open rules accordions with Tab + Enter → pinned by the keyboard test in Task 8.
5. **Visitor with reduced motion** must see content immediately with no slide-in styles → pinned by the reduced-motion test in Task 7.

`src/lib/contrast.ts`:
```ts
import { tokens } from '../theme/tokens';

function channel(value: number): number {
  const s = value / 255;
  return s <= 0.04045 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4;
}

/** WCAG 2.x relative luminance of a `#RRGGBB` color. */
export function relativeLuminance(hex: string): number {
  const match = /^#([0-9a-f]{6})$/i.exec(hex);
  if (!match) throw new Error(`Expected a #RRGGBB color, got "${hex}"`);
  const n = parseInt(match[1], 16);
  const r = (n >> 16) & 255;
  const g = (n >> 8) & 255;
  const b = n & 255;
  return 0.2126 * channel(r) + 0.7152 * channel(g) + 0.0722 * channel(b);
}

/** WCAG contrast ratio between two `#RRGGBB` colors (1–21). */
export function contrastRatio(a: string, b: string): number {
  const la = relativeLuminance(a);
  const lb = relativeLuminance(b);
  const [hi, lo] = la > lb ? [la, lb] : [lb, la];
  return (hi + 0.05) / (lo + 0.05);
}

/** Returns whichever of `light`/`dark` has more contrast against `fill`. */
export function readableTextOn(fill: string, light: string = tokens.paper, dark: string = tokens.ink): string {
  return contrastRatio(fill, light) >= contrastRatio(fill, dark) ? light : dark;
}
```

```ts
export type CountdownState =

const DAY = 86_400;
const HOUR = 3_600;
const MINUTE = 60;

/**
 * Pure countdown math. `target` must be ISO 8601 with an explicit offset
 * (`Z` or `±HH:MM`); `now` is epoch milliseconds.
 */
export function getCountdownState(target: string | null, now: number): CountdownState {
  if (target === null) return { status: 'unscheduled' };
  const targetMs = Date.parse(target);
  if (Number.isNaN(targetMs)) return { status: 'unscheduled' };

  let remaining = Math.floor((targetMs - now) / 1000);
  if (remaining <= 0) return { status: 'started' };

  const days = Math.floor(remaining / DAY);
  remaining -= days * DAY;
  const hours = Math.floor(remaining / HOUR);
  remaining -= hours * HOUR;
  const minutes = Math.floor(remaining / MINUTE);
  const seconds = remaining - minutes * MINUTE;
  return { status: 'counting', timeLeft: { days, hours, minutes, seconds } };
}
```

```tsx
  /** ISO 8601 with offset, or null while the date is unknown. */

  colors?: readonly string[];
  unscheduledLabel?: string;
  startedLabel?: string;

  { key: 'days', singular: 'day', plural: 'days' },
  { key: 'hours', singular: 'hour', plural: 'hours' },
  { key: 'minutes', singular: 'minute', plural: 'minutes' },
  { key: 'seconds', singular: 'second', plural: 'seconds' },

export default function Countdown({
  target,
  colors = countdownColors,
  unscheduledLabel = 'Date to be announced',
  startedLabel = 'The championship has started',
}: CountdownProps) {
  const [now, setNow] = useState(() => Date.now());
  const state = getCountdownState(target, now);
  const isCounting = state.status === 'counting';

  useEffect(() => {
    if (!isCounting) return;
    const timer = setInterval(() => setNow(Date.now()), 1000);
    return () => clearInterval(timer);
  }, [isCounting]);

        role="status"
        sx={{ fontWeight: 800, fontSize: { xs: '1.25rem', md: '1.75rem' }, color: tokens.ink, letterSpacing: '0.04em' }}

        {state.status === 'unscheduled' ? unscheduledLabel : startedLabel}

  }

      role="timer"
      aria-label="Time until the championship starts"
      sx={{ display: 'flex', justifyContent: 'center', gap: { xs: 2, md: 4 } }}
    >
      {UNITS.map((unit, index) => {
        const value = state.timeLeft[unit.key];
        return (

              component="span"

                display: 'block',

                display: 'block',

                fontFamily: fonts.mono,

              {value === 1 ? unit.singular : unit.plural}
```

```js
// Renders every art/*.svg postcard to responsive WebP files in public/postcards/.
// Keep WIDTHS in sync with POSTCARD_WIDTHS in src/lib/postcardAssets.ts.
import { mkdir, readFile, readdir } from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import sharp from 'sharp';

const root = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
const artDir = path.join(root, 'art');
const outDir = path.join(root, 'public', 'postcards');
const WIDTHS = [800, 1600];
const QUALITY = 82;

async function exportPostcard(file) {
  const id = path.basename(file, '.svg');
  const svg = await readFile(path.join(artDir, file));
  const { width: baseWidth } = await sharp(svg).metadata();
  if (!baseWidth) throw new Error(`${file}: could not read the SVG width`);

  for (const width of WIDTHS) {
    // Rasterize at a density high enough that we only ever scale down.
    const density = Math.max(72, Math.ceil((72 * width) / baseWidth));
    const outFile = path.join(outDir, `${id}-${width}.webp`);
    const info = await sharp(svg, { density })
      .resize({ width })
      .webp({ quality: QUALITY })
      .toFile(outFile);
    console.log(`${path.relative(root, outFile)}  ${info.width}x${info.height}  ${Math.round(info.size / 1024)} KB`);
  }
}

const files = (await readdir(artDir)).filter((f) => f.endsWith('.svg')).sort();
if (files.length === 0) throw new Error(`No SVG postcards found in ${artDir}`);
await mkdir(outDir, { recursive: true });
for (const file of files) {
  await exportPostcard(file);
}
```

```ts
/** Installs a window.matchMedia stub (jsdom has none). Returns a restore function. */
export function mockMatchMedia(matches: (query: string) => boolean): () => void {
  const stub = (query: string): MediaQueryList => ({
    matches: matches(query),
    media: query,
    onchange: null,
    addListener: () => {},
    removeListener: () => {},
    addEventListener: () => {},
    removeEventListener: () => {},
    dispatchEvent: () => false,
  });
  Object.defineProperty(window, 'matchMedia', { configurable: true, writable: true, value: stub });
  return () => {
    delete (window as { matchMedia?: unknown }).matchMedia;
  };
}
```

```ts
import { useSyncExternalStore } from 'react';

const QUERY = '(prefers-reduced-motion: reduce)';

function hasMatchMedia(): boolean {
  return typeof window !== 'undefined' && typeof window.matchMedia === 'function';
}

function subscribe(onChange: () => void): () => void {
  if (!hasMatchMedia()) return () => {};
  const list = window.matchMedia(QUERY);
  list.addEventListener('change', onChange);
  return () => list.removeEventListener('change', onChange);
}

function getSnapshot(): boolean {
  return hasMatchMedia() && window.matchMedia(QUERY).matches;
}

/** True when the visitor asked the OS to reduce motion; false without matchMedia. */
export function usePrefersReducedMotion(): boolean {
  return useSyncExternalStore(subscribe, getSnapshot, () => false);
}
```

```tsx
import type { CSSProperties, ReactNode } from 'react';
import { useInView } from 'react-intersection-observer';
import { usePrefersReducedMotion } from '../hooks/usePrefersReducedMotion';

export type AnimateVariant = 'fade' | 'rise' | 'slide-from-left' | 'slide-from-right';

const HIDDEN_TRANSFORM: Record<AnimateVariant, string> = {
  fade: 'none',
  rise: 'translateY(32px)',
  'slide-from-left': 'translateX(-56px)',
  'slide-from-right': 'translateX(56px)',
};

type AnimateOnViewProps = {
  children: ReactNode;
  variant?: AnimateVariant;
  timeout?: number;
  threshold?: number;
};

/**
 * Reveals children the first time they scroll into view (HackMTY pattern).
 * Uses a short CSS translate instead of MUI Slide, which moves content by the
 * full window width and causes horizontal overflow.
 */
export default function AnimateOnView({ children, variant = 'fade', timeout = 700, threshold = 0.15 }: AnimateOnViewProps) {
  const reducedMotion = usePrefersReducedMotion();
  const { ref, inView } = useInView({ triggerOnce: true, threshold, fallbackInView: true });

  if (reducedMotion) {
    return <div data-testid="animate-on-view">{children}</div>;
  }

  const style: CSSProperties = {
    opacity: inView ? 1 : 0,
    transform: inView ? 'none' : HIDDEN_TRANSFORM[variant],
    transition: `opacity ${timeout}ms ease-out, transform ${timeout}ms ease-out`,
  };
  return (
    <div ref={ref} data-testid="animate-on-view" style={style}>
      {children}
    </div>
  );
}
```

```ts
import { vi } from 'vitest';

type ObserverRecord = { callback: IntersectionObserverCallback; elements: Set<Element> };

/**
 * Replaces IntersectionObserver with a controllable fake.
 * Call vi.unstubAllGlobals() in afterEach to remove it.
 */
export function installIntersectionObserverMock() {
  const records: ObserverRecord[] = [];

  class MockIntersectionObserver {
    readonly root = null;
    readonly rootMargin = '0px';
    readonly thresholds: number[] = [0];
    private readonly record: ObserverRecord;

    constructor(callback: IntersectionObserverCallback) {
      this.record = { callback, elements: new Set() };
      records.push(this.record);
    }
    observe(element: Element) {
      this.record.elements.add(element);
    }
    unobserve(element: Element) {
      this.record.elements.delete(element);
    }
    disconnect() {
      this.record.elements.clear();
    }
    takeRecords(): IntersectionObserverEntry[] {
      return [];
    }
  }

  vi.stubGlobal('IntersectionObserver', MockIntersectionObserver);

  return {
    /** Reports the visible height (px) of observed elements, keyed by element id. */
    setVisibleHeights(heights: Record<string, number>) {
      for (const record of records) {
        const entries = [...record.elements]
          .filter((element) => element.id in heights)
          .map((element) => {
            const height = heights[element.id];
            return {
              target: element,
              isIntersecting: height > 0,
              intersectionRatio: height > 0 ? 1 : 0,
              intersectionRect: { height } as DOMRectReadOnly,
              boundingClientRect: {} as DOMRectReadOnly,
              rootBounds: null,
              time: 0,
            } as IntersectionObserverEntry;
          });
        if (entries.length > 0) record.callback(entries, {} as IntersectionObserver);
      }
    },
  };
}
```

`src/hooks/useActiveSection.ts`:
```ts
import { useEffect, useState } from 'react';
import { HEADER_HEIGHT } from '../theme/layout';

const THRESHOLDS = Array.from({ length: 11 }, (_, i) => i / 10);

/**
 * Scroll spy: returns the id of the section with the most visible height
 * below the sticky header. Pass a stable (module-level) array of ids.
 */
export function useActiveSection(ids: readonly string[]): string | undefined {
  const key = ids.join('|');
  const [active, setActive] = useState<string | undefined>(ids[0]);

  useEffect(() => {
    if (typeof IntersectionObserver === 'undefined') return;
    const list = key.split('|');
    const visible = new Map<string, number>();

    const observer = new IntersectionObserver(
      (entries) => {
        for (const entry of entries) {
          visible.set(entry.target.id, entry.isIntersecting ? entry.intersectionRect.height : 0);
        }
        let best: string | undefined;
        let bestHeight = 0;
        for (const id of list) {
          const height = visible.get(id) ?? 0;
          if (height > bestHeight) {
            best = id;
            bestHeight = height;
          }
        }
        if (best !== undefined) setActive(best);
      },
      { rootMargin: `-${HEADER_HEIGHT}px 0px 0px 0px`, threshold: THRESHOLDS },
    );

    for (const id of list) {
      const element = document.getElementById(id);
      if (element) observer.observe(element);
    }
    return () => observer.disconnect();
  }, [key]);

  return active;
}
```

````markdown
Single-page site for the 2027 ICPC Latin America Championship in Monterrey,

## Editing content

All text lives in `src/content/`:

| File | What it holds |
|---|---|
| `event.ts` | Name, city, dates, host, venue, countdown target, links. Every `TBD` here is an open item. |
| `hero.ts` | Hero eyebrow and hero postcard. |
| `about.ts` | About blocks (title, paragraphs, optional postcard). |
| `rules.ts` | Rules intro and accordion entries. |
| `footer.ts` | Footer copyright and links. |

Find remaining placeholders with `grep -rn "TBD" src/content`.

Countdown: set `event.countdownTarget` to ISO 8601 **with the Monterrey
offset**, e.g. `'2027-11-12T09:00:00-06:00'`. A test rejects targets without an
offset.

## Adding a postcard

1. Save the SVG as `art/<id>.svg` (e.g. `art/macroplaza.svg`).
2. Run `npm run postcards`.
3. Add an entry to `src/content/postcards.ts` (id, place, alt, orientation, and
   the SVG `viewBox` width/height).
4. Reference it from a block: `postcardId: '<id>'` in `about.ts` or `rules.ts`.
5. `npm test` checks the id exists and both WebP sizes were exported.

## Colors

`src/theme/tokens.ts` holds the palette. The ICPC blue/red/yellow/green are
approximations — replace them with official values there, then run `npm test`
to confirm text contrast still passes.

## Deploying

`npm run build` produces a static `dist/` folder that works on any static host
with no rewrite rules (it is a single page). If the site is served from a
sub-path such as `/icpc2027/`, set `base: '/icpc2027/'` in `vite.config.ts`.

## Reference

A local copy of the 2026 site lives next to this repo in `../latam2026-mirror/`
(reference only; not part of this project).
````
